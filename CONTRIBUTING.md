# Contributing Guidelines

Hi there! 👋 Thanks for your interest in contributing to this project.

This is a solo developer project, so things are kept simple. Here's how you can help:

---

## 🐛 Reporting Bugs

If you find a bug or unexpected behavior:

- Open an issue with a clear description.
- Include steps to reproduce the problem.
- Screenshots or logs are helpful!

---

## 💡 Suggesting Features

Got a cool idea or improvement?

- Feel free to open an issue and tag it as a `feature request`.
- Describe what you'd like to see and why it would help.

---

## 🛠 Submitting a Pull Request

1. Fork the repo.
2. Create a new branch: `git checkout -b your-feature-name`
3. Commit your changes: `git commit -m "Add something awesome"`
4. Push to your branch: `git push origin your-feature-name`
5. Open a pull request and explain your changes.

---

## ✅ Code Style

- Use clear and meaningful commit messages.
- Keep code clean and well-commented.
- Follow any existing styles in the project.

---

## 🙏 Thank You!

Thanks for taking the time to help improve this project. Every bit of feedback and contribution means a lot!

Happy coding! 💻
